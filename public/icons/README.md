# App Icons

This directory should contain the following app icons for the PWA:

## Required Icons:
- icon-72x72.png
- icon-96x96.png  
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Additional Icons:
- qr-icon.png (96x96) - for QR scanner shortcut
- calendar-icon.png (96x96) - for calendar shortcut

## Icon Requirements:
- PNG format
- Square aspect ratio
- High quality/resolution
- Should represent your gym/fitness brand
- Consider maskable icon design for Android

You can generate these icons from a single high-resolution source image using online tools like:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
- https://favicon.io/

## Current Status:
Icons are referenced in manifest.json but need to be created and placed in this directory.
